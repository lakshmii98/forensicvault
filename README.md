# \# ForensicVault

# 

# \## Digital Evidence Recovery, Integrity \& Secure Erasure Platform

# 

# ForensicVault is a digital forensics platform designed to help investigators recover fragmented evidence, validate recovered files, detect possible image manipulation, maintain evidence integrity, and perform controlled secure erasure.

# 

# \## Key Features

# 

# \- File carving and digital evidence recovery

# \- Automatic fragmented file ordering

# \- Fragment reconstruction and validation

# \- Recovery confidence scoring

# \- Image tamper detection

# \- SHA-256 evidence integrity and hash chain

# \- Chain of custody support

# \- Secure file and folder erasure

# \- SSD/TRIM awareness

# \- Controlled drive-erasure simulation

# \- Forensic report generation

# \- FastAPI backend with React frontend

#
